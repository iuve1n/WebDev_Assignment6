# Assignment 6

This project has jQuery examples on separate pages. Tasks 0 and 1 cover setup and selectors. Tasks 2 through 4 demonstrate visibility, fade, and slide effects. Tasks 5 through 7 cover list items, attributes, and live form input. Tasks 8 through 10 show how to move and resize elements with jQuery animations. Task 11 is a small accordion made with jQuery.

## Technologies

- HTML
- CSS
- JavaScript and jQuery 3.7.1

## How to run

Open `index.html` in a browser and use the navigation to switch tasks. Open the browser console to see the ready message in Task 0. An internet connection is needed to load jQuery from its CDN.
